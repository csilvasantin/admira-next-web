# /demo starbucks 180

One shared Expert command opens Studio’s native 180 demo: MacStudio V–H–V, then MacBookPro16 H, returning to MacStudio. The MacMini is absent from its program, launch requests and assignments. The existing /contenido starbucks 360 route remains available.

The preview supports 3D and Matrix, with movable/resizable/closable panels and H to hide them. Explicit start requires the normal Studio owner session. Only four fixed themed playlists are installed, then those same four players receive resume and sync. The UI verifies current IDs, media URLs, synchronization and fresh heartbeat before reporting playback. A queued request alone is not playback.

Admirito gets exact extra demo commands from the host dispatcher’s catalog; the face does not implement another Starbucks parser. Existing demo controls and numeric demonstrations retain their routes.
