Organigrama tecnológico

Cómo se hablan las webs de Admira: admiranext.com es el hub, cinco patas hacen el trabajo, admira.live lo controla y unos pocos servicios compartidos llevan los datos de un sitio a otro.

Pasa el ratón por una caja para ver sus flechas. Haz clic para abrir su ficha.

Cómo leer esto

  • El centro (cian) es admiranext.com: define los clientes y publica lo común.
  • Las cinco cajas de color son las patas: cada una hace un trabajo (crear, gestionar, emitir, mantener, vender).
  • Arriba, admira.live: la capa de control, donde el Consejo y la flota de agentes ven y coordinan todo.
  • Las cajas grises son servicios compartidos: los usan varias patas a la vez.
  • Una flecha va de quien pide a quien responde; la etiqueta dice qué viaja.
  • Una flecha discontinua está por confirmar: hay pistas en el código, pero no una prueba clara.
  • Abajo, el suelo: Cloudflare aloja todo y GitHub guarda el código.
