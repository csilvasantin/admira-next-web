# Admira Next Web

Corporate website for Admira Next, a Robot as a Service and IoT company.

The site is static, multipage and available in Spanish, English and Catalan.

## Pages

- `index.html`
- `servicios.html`
- `plataforma.html`
- `casos.html`
- `contacto.html`

## Local preview

```sh
python3 -m http.server 4827
```
