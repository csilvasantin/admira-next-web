# Pixeria · novedades de Trinity / Trinity updates

Fecha de la muestra / Sample date: **9 octubre / October 2026**.

ES: `/demo pixeria novedades` abre un recorrido preparado de ocho capítulos con narración opcional. EN: `/demo pixeria updates` or `/demo pixeria news` opens the same eight-chapter prepared tour in English. `/demo studio novedades` is an alias. Web: https://www.admiranext.com/demo/pixeria-novedades/?lang=es · English: https://www.admiranext.com/demo/pixeria-novedades/?lang=en.

## Tutorial ES

1. Abre la demo y pulsa **Reproducir recorrido**; activa **Escuchar explicación** si quieres narración. El comando abre el recorrido iniciado, con el sonido apagado hasta que lo actives.
2. Compara los previos de Creador, el acompañamiento de Admirito, los pasos Clásico y Formatos especiales, la revisión del anuncio, la composición guardada en Stock, los proveedores y la ayuda MCP.
3. Usa **Anterior**, **Siguiente**, **Pausar**, **Continuar**, **Reiniciar** o los botones de capítulos. En Experto: `/demo pausa`, `/demo reanudar`, `/demo siguiente`, `/demo estado`, `/demo stop`.
4. **Ver vídeo completo** reproduce el MP4 narrado del recorrido, en el idioma seleccionado.
5. El último capítulo permite abrir **URBAN FLOW en el gemelo 360**. Se reutilizan sus medios existentes; abrir el gemelo no pide otra generación.
6. En el [editor de demos](https://www.admiranext.com/subdemos/), selecciona **Pixeria · novedades · temporal** y pulsa **Empezar** o **Ensayar recorrido**. Puedes cambiar la definición con **Editar**.
7. Cuando quieras retirarla, pulsa **Eliminar** en la fila **Pixeria · novedades · 09.10.2026** dentro de Studio. El editor quita esa definición y sus referencias de los proyectos de este navegador. Después puedes usar **Quitar el activo** para retirar el proyecto temporal. Las otras demos y la campaña original se conservan.

No se borra automáticamente. Exportar antes de eliminar conserva una copia recuperable; importar ese JSON restaura la definición. La edición y eliminación del editor son locales a este navegador y dominio, no una baja global de archivos públicos. Si quieres retirar también los archivos publicados, debe retirarse esta carpeta y el alias del CLI en un nuevo despliegue.

## English tutorial

1. Open the demo and click **Play tour**; enable **Listen to narration** for audio. The command starts the tour with sound off until you enable it.
2. Compare Creator previews, Admirito, Classic and Special Formats, ad review, Stock composition, providers and live MCP help.
3. Use **Previous**, **Next**, **Pause**, **Resume**, **Restart** or chapter buttons. Expert commands: `/demo pause`, `/demo resume`, `/demo next`, `/demo status`, `/demo stop`.
4. **Watch full video** plays the narrated MP4 in the selected language.
5. The last chapter opens the **URBAN FLOW 360 twin**, reusing existing media without requesting generation.
6. In the [demo editor](https://www.admiranext.com/subdemos/), select **Pixeria · novedades · temporal**, then **Empezar** or **Ensayar recorrido**. **Editar** edits its definition.
7. Delete **Pixeria · novedades · 09.10.2026** in the Studio list when you want to remove it. This removes that definition and its project references from this browser. Use **Quitar el activo** to remove the temporary project afterward. Other demos and the original campaign remain.

There is no automatic deletion. Export before deleting for recovery; importing the export restores the entry. Editor edits and deletion are browser-local, not global removal of public media. Removing published files also requires removing this folder and its CLI alias in a new deployment.
